How it works

Each row in the database contains a single BLOB column holding a serialised test.Person protobuf message. Every value displayed in the table above — name, age, score, city, tags — is extracted directly from that blob at query time using the protobuf_extract() SQLite function: 

SELECT
  protobuf_extract(proto_data, :descriptor, 'test.Person', 'name')       AS name,
  protobuf_extract(proto_data, :descriptor, 'test.Person', 'age')        AS age,
  protobuf_extract(proto_data, :descriptor, 'test.Person', 'address.city') AS city
FROM people_personrecord
ORDER BY protobuf_extract(proto_data, :descriptor, 'test.Person', 'score') DESC;

Filtering, ordering, and aggregation (AVG, COUNT) all work on the extracted values through Django's standard ORM, with no schema migrations needed when the protobuf schema changes.
