test.Record has oneof source { BranchA branch_a; BranchB branch_b; }. Previously, querying an inactive branch returned the proto3 default (empty string ""), making COALESCE useless. Now inactive branches return NULL: 

-- branch_b is set; branch_a.label is now NULL (not "")
SELECT
  protobuf_extract(proto_data, :d, 'test.Record', 'branch_a.label')  -- NULL
  protobuf_extract(proto_data, :d, 'test.Record', 'branch_b.label')  -- "north"
  COALESCE(
    protobuf_extract(proto_data, :d, 'test.Record', 'branch_a.label'),
    protobuf_extract(proto_data, :d, 'test.Record', 'branch_b.label')
  )  -- "north"  ✓
FROM people_recordentry;

The Combined Label column above is computed exactly this way, via Django's Coalesce() expression applied after proto_view.apply().

protobuf_which_oneof(data, descriptor, message_type, oneof_name) returns the active field name as a string, or NULL. The Type column and sorting in All Records mode are driven by this function via OneofColumn: 

SELECT
  protobuf_which_oneof(
    proto_data, :d, 'test.Record', 'source'
  ) AS source_type
FROM people_recordentry
ORDER BY source_type;   -- branch_a rows, then branch_b rows

In Django: qs = proto_view.apply(qs) adds the source_type annotation; qs.order_by("source_type") groups by branch.

For fields you query frequently, add a generated column so SQLite caches the extracted value and it can be indexed: 

-- Migration RunSQL:
ALTER TABLE people_recordentry
  ADD COLUMN branch_a_label TEXT GENERATED ALWAYS AS (
    protobuf_extract(proto_data,
                     X'<descriptor_hex>',
                     'test.Record',
                     'branch_a.label')
  ) VIRTUAL;

CREATE INDEX people_recordentry_branch_a_label
    ON people_recordentry(branch_a_label);

Or via the Django helper (requires Django 5.0+):

from django_sqlite_protobuf.expressions import (
    make_protobuf_generated_field,
    make_protobuf_index,
    make_protobuf_which_oneof_generated_field,
)

class RecordEntry(models.Model):
    proto_data     = models.BinaryField()
    branch_a_label = make_protobuf_generated_field(
        "proto_data", DESCRIPTOR,
        "test.Record", "branch_a.label",
        output_field=models.TextField(),
        db_persist=True,   # STORED → indexable
    )
    source_type = make_protobuf_which_oneof_generated_field(
        "proto_data", DESCRIPTOR,
        "test.Record", "source",
        db_persist=True,
    )
    class Meta:
        indexes = [
            models.Index(fields=["branch_a_label"],
                         name="recordentry_branch_a_label_idx"),
            models.Index(fields=["source_type"],
                         name="recordentry_source_type_idx"),
        ]

After the column exists, use ModelColumn and ModelDynamicFilter in a ProtoView to display and filter it directly — no protobuf extraction overhead at query time.
