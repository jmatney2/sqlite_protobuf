oneOf: NULL for inactive branches + COALESCE

test.Record has oneof source { BranchA branch_a; BranchB branch_b; }. Inactive branches return NULL, making COALESCE work correctly: 

-- branch_b is set; branch_a.label returns NULL (not "")
SELECT COALESCE(
    protobuf_extract(proto_data, :d, 'test.Record', 'branch_a.label'),
    protobuf_extract(proto_data, :d, 'test.Record', 'branch_b.label')
)  -- "north"  ✓
FROM people_recordentry;

The Combined Label column is computed exactly this way, via Django's Coalesce() applied after proto_view.apply().

protobuf_which_oneof() — sort and group by type

protobuf_which_oneof(data, descriptor, message_type, oneof_name) returns the active field name as a string, or NULL. The Type column and branch-type filter in All Records mode use this via OneofColumn: 

SELECT protobuf_which_oneof(
    proto_data, :d, 'test.Record', 'source'
) AS source_type
FROM people_recordentry
ORDER BY source_type;   -- branch_a rows, then branch_b rows
Generated columns + indexes (for scale)

For millions of rows, sorting via protobuf_extract requires a full-table scan with per-row decode. Add a stored generated column to pre-compute and index the value: 

from django_sqlite_protobuf.expressions import (
    make_protobuf_generated_field,
    make_protobuf_which_oneof_generated_field,
)

class RecordEntry(models.Model):
    proto_data  = models.BinaryField()
    source_type = make_protobuf_which_oneof_generated_field(
        "proto_data", DescriptorRef("test"),
        "test.Record", "source",
        db_persist=True,          # STORED → indexable
    )
    class Meta:
        indexes = [
            models.Index(fields=["source_type"],
                         name="recordentry_source_type_idx"),
        ]

After the column exists, use ModelColumn / ModelDynamicFilter in a ProtoView — the value is read directly from the index with no protobuf decoding at query time.
